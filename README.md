# 📺 Content Performance Analysis

> A business intelligence project analyzing viewer engagement and content performance for a digital media platform using SQL and Power BI.

---

# 📖 Project Overview

This project focuses on analyzing content performance and viewer engagement to support data-driven content strategy and business decision-making.

Using SQL for data preparation and Power BI for visualization, the project transforms raw viewership and catalog data into meaningful insights through interactive dashboards and executive reporting.

---

# 🎯 Business Objectives

The project aimed to answer key business questions such as:

- Which content sources generate the highest viewership?
- What is the average viewing progress and completion rate?
- Which series attract the most unique viewers?
- How does newly published content perform compared to older content?
- How many viewers return to watch content on different days?
- Which titles perform best in terms of audience engagement?
