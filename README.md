# 📺 Content Performance Analysis

> A data analytics project focused on evaluating content performance, viewer engagement, and audience behavior using SQL and Power BI to deliver actionable business insights.

---

# 📖 Project Overview

Understanding how audiences interact with digital content is essential for improving engagement, retention, and content strategy. This project analyzes viewership and catalog data to uncover viewing patterns, measure content performance, and provide recommendations that support data-driven decision-making.

The analysis includes data preparation using SQL, dashboard development in Power BI, and executive reporting to communicate key findings.

---

## 📂 Dataset

> **Note:** The original datasets are not included in this repository because they exceed GitHub's file size limits. The repository includes the SQL scripts, Power BI dashboard, exported analysis, and final report to demonstrate the complete analytical workflow.

---

# 🎯 Business Objectives

This project addresses the following business questions:

- Which traffic sources generate the highest number of views?
- Which content categories perform best?
- What is the average viewing progress?
- What is the average completion rate?
- Which series attract the most unique viewers?
- How does newer content perform compared to older content?
- What percentage of viewers return on different days?
- Which episodes receive the highest number of views?
